# Windows Agent Cleanup

For engineering tasks, read `AGENTS.md`, then the engineering route in
`README_AI.md`. Keep persistent project rules there; load operational references
only for the current task. A build or development task grants no cleanup permission.

For cleanup use, read `README_AI.md` to locate the shared `project-cleanup` Skill.
That Skill owns plan selection, evidence-based classification and bulk execution.
Use its relative references as needed. Installation does not authorize deletion.

RC and Release publication require owner-returned Windows build/test evidence
and review of the exact revision. CI produces unpublished test artifacts only.
The owner-directed first public `v2.0.0` distribution follows the scoped
exception in `docs/publication.md`; keep supplied binary bytes and pending
acceptance evidence honest. It does not authorize later publication.
